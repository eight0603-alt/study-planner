# Study Planner

個人備考行事曆與習慣追蹤工具，為 2027 年會計師考試打造。

## 功能

- 📅 **月曆** — 課程、複習、個人行程一覽
- 📋 **每日計畫** — 當日行程 + 待辦清單 + 子彈筆記
- ✅ **習慣追蹤** — 英文、日文等每日習慣打勾記錄
- 📊 **儀表板** — 課程進度條、學習時數、距考試倒數

## 部署步驟

1. 在 GitHub 建立一個名為 `study-planner` 的 repository（設為 Public）
2. 把這個資料夾的所有檔案上傳到 main branch
3. 到 repo 的 **Settings → Pages → Source** 選 **GitHub Actions**
4. 推送後等約 1 分鐘，網址 `https://eight0603-alt.github.io/study-planner/` 就會上線

## 本地預覽

直接用瀏覽器打開 `index.html` 即可（無需安裝任何東西）。

## 資料儲存

所有筆記、待辦、習慣記錄都存在瀏覽器的 localStorage，不需要帳號或網路。
